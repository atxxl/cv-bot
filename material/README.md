# material/

Everything the bot is allowed to know lives here, as plain markdown, written or approved by the owner.

Rules:
- One file per topic (`mai.md`, `thesis.md`, `agent-system.md`, `education.md`, ...). Short paragraphs or bullet lines; each line becomes a citable unit.
- Only facts that are already on the public CV page or that the owner has decided to make public.
- No contact details beyond what the CV page shows. No names of colleagues or clients.
- If something is uncertain, leave it out rather than hedge it in.

Agents do not edit this directory. If the bot needs more material to answer a reasonable question, open an issue describing the gap.
